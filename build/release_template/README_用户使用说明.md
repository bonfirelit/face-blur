# FaceBlur Pro 使用说明

## 什么是 FaceBlur Pro？

FaceBlur Pro 是一款智能视频人脸打码工具，可以自动检测视频中的人脸并进行模糊或马赛克处理。

## 系统要求

- **操作系统：** Windows 7/10/11（64位）或 Linux
- **内存：** 建议 4GB 以上
- **硬盘空间：** 至少 500MB 可用空间
- **网络：** 首次运行需要联网下载模型文件（约 100MB）

## 重要说明

**无需安装任何依赖！**

本程序已经内置了所有必要的组件：
- ✅ Python 解释器（内置）
- ✅ 所有必要的库（内置）
- ✅ 人脸检测模型（首次运行自动下载）

你只需要：
1. 解压文件
2. 双击启动脚本
3. 开始使用

**不需要**安装 Python 或任何其他软件！

## 快速开始

### Windows 用户

1. 双击 `启动程序.bat`
2. 等待程序启动（首次启动较慢，请耐心等待）
3. 浏览器会自动打开操作界面

### Linux 用户

1. 打开终端，进入程序所在目录
2. 执行：`./启动程序.sh`
3. 浏览器会自动打开操作界面

## 使用方法

### 第一步：上传视频

点击界面中间的上传区域，选择要处理的视频文件。

支持的格式：MP4, AVI, MOV, MKV

### 第二步：调整参数（可选）

在左侧边栏可以调整以下参数：

| 参数 | 说明 |
|------|------|
| 打码效果 | 高斯模糊（柔和）或马赛克（方块） |
| 强度调节 | 控制模糊程度或马赛克大小 |
| 检测精度 | 置信度越高，检测越严格 |
| 遮罩形状 | 调整椭圆遮罩的大小 |
| 智能跟踪 | 开启后可大幅提升处理速度 |
| 检测间隔 | 控制检测频率，值越大速度越快 |

**推荐设置：**
- 启用智能跟踪
- 检测间隔设置为 5-10 帧

### 第三步：开始处理

1. 调整好参数后，点击 **"开始处理"** 按钮
2. 等待处理完成（显示进度条）
3. 处理完成后点击 **"下载处理后的视频"** 保存结果

## 常见问题

### Q: 我需要安装 Python 吗？
A: **不需要！** 本程序已经内置了 Python 解释器和所有依赖库，直接运行即可。

### Q: 首次启动很慢？
A: 首次运行需要下载人脸检测模型文件（约 100MB），请耐心等待。后续启动会快很多。

### Q: 处理速度很慢？
A: 建议开启"智能跟踪"并将"检测间隔"设置为 5-10 帧，可以大幅提升速度。

### Q: 有些人脸没有被检测到？
A: 尝试降低"置信度阈值"到 0.3 或 0.4。

### Q: 检测到了不需要的人脸？
A: 提高"置信度阈值"到 0.6 或 0.7。

### Q: 程序无法启动？
A: 请确保：
1. 系统是 64 位
2. 有足够的磁盘空间
3. 首次运行时网络正常
